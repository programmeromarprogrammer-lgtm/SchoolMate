SchoolMate - صفحة تحميل التطبيق

محتويات المشروع:
- index.html
- style.css

طريقة الرفع على GitHub Pages:
1. أنشئ Repository جديد على GitHub.
2. ارفع index.html و style.css إلى الـRepository.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch.
5. اختر Branch: main ثم مجلد / (root).
6. اضغط Save.
7. بعد اكتمال النشر سيظهر رابط الصفحة.

ملاحظة:
زر تحميل التطبيق مرتبط حاليًا بملف APK الذي تم إنشاؤه بواسطة Expo.
إذا تم إنشاء APK جديد لاحقًا، استبدل رابط APK القديم داخل index.html بالرابط الجديد.

الصفحة لا تحتوي على أي مكتبات خارجية أو ملفات إضافية، وهي متجاوبة مع الهاتف والكمبيوتر.
